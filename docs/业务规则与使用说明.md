# SOP计划看板

双击 **启动工作台.cmd**，服务就绪后自动打开 http://127.0.0.1:8876 ，命令窗口保持运行。关闭这个窗口或按 **Ctrl+C** 即停止工作台，不再使用独立停止脚本。仅关闭浏览器页面不会停止服务；再次双击会打开已有网页，服务仍由原命令窗口控制。启动失败时窗口会保留具体原因，便于查看。

启动脚本按自身所在目录寻找代码和数据，项目文件夹更名后仍可使用；内部调用 `start-sop.ps1` 查找Python并在同一窗口运行，不创建隐藏后台服务。旧版隐藏进程只在工作目录、启动时间、执行文件和端口归属全部核对通过后由新入口自动接管。看板仍使用四位数端口8876。

## 两种入口，一份计划

SOP计划统一保存在本项目数据库。可以直接点击“网页维护”保存计划，不需要先创建Excel；Excel是可选维护入口。两种入口按「计划记录编码＋月份」定位同一条SOP计划；不是分别保存两套表再相加。

页面、输入维护模板和导出Excel的主标题统一为“SOP计划表”，不随月份、M+6/全年视图或是否展示版本、锁单而变化。Excel的月份范围单独展示，便于识别对应周期。

- **表格维护**：打开 `input_file/SOP计划维护.xlsx`，在一张“SOP计划”长表填写。月份从最早需要年份的1月连续排到当前最长计划截止月，按品牌、车型列出版本。2026年10月提供2026年1月—2027年12月；每年9月自动扩展至次年12月，7、8月分别补足至次年1、2月。每年12月后增加年度合计，车型与品牌自动汇总。可填“车型总量（不分版本）”行或版本行的月度SOP计划量；过去月份灰底仍可修正，未开放的远期月只读保留。保存后，服务约每8秒检查一次修改并同步到网页。
- **维护粒度**：底线是车型＋年款，版本拆分可选。同车型年款、同月已填车型总量时优先使用该总量，保留版本明细但不重复相加；清空总量后恢复版本自动汇总。0是明确零值，仍优先于版本量。品牌、年度、汇总代际和匹配率采用同一规则，不同年款独立。Excel中车型总量使用“车型总量（不分版本）”输入行，与自动计算的“车型 合计”行区分。
- **网页维护**：日常统一点击“网页维护”，直接在车型行填写各月总量，展开即可修改版本量，无需切换维护粒度；留空的车型输入框提示已保存的版本汇总值。点击可编辑的版本计划数字也进入同一主表维护。月份直接对应表格列，当前月自动突出，不再设置“维护月份”。表内可以改品牌、车型和版本名，在车型旁新增版本，或使用“新增车型”。整车型改名和删除作用于该车型年款下全部版本，包含隐藏的版本；其他年款独立。已有车型改名保留原年款，新增年款使用“新增车型”。填写维护人后在右上角点击“保存修改”；保存前可撤销删除或取消整批修改，展开、收起版本和切换锁单显示不会丢失草稿。删除已有行按停用处理，保留原计划和历史。锁单数、合计及自动汇总代际只读。留空表示待维护，0表示明确零值。合计保存后更新；保存时整批校验，遇到其他人或Excel已更新造成的冲突会保留草稿并提示核对，不部分提交。如已建立维护表，保存后也会同步更新该表；没有维护表时直接保存在统一数据库，不创建维护表。预测销量作为原有独立字段保留，本次SOP修改不会清空它。
- **导出后回填**：网页点击“导出”，默认下载与维护输入表一致的完整模板：全部车型版本、完整计划周期、只含计划量。表头、说明、行列布局、合并、格式及合计公式一致。修改车型总量或版本行的月度SOP计划量并保存，再在网页点击“导入Excel”选择该文件。也可直接在主表插入、删除版本计划明细行或修改名称。导入写入同一份计划；若维护表已建立，也会同步更新维护表。可自选增加锁单行、裁剪月份、仅导出当前筛选，或取消版本明细查看只读车型汇总；点击“恢复维护表格式”可切回完整模板。
- **旧副本和冲突**：导入按导出时的基准识别真正修改过的单元格，未改内容不会覆盖网页上较新的计划。相同月份、版本两边都改过且不一致时，整次导入暂停并显示冲突，选择保留网页值或使用表格值后再提交。导出范围外的数据和预测销量不变。
- **Excel占用文件**：网页修改会先写入统一数据库，关闭Excel后完成回写；页面会提示“待回写”。
- **同时修改**：相同单元格在网页、Excel两边都改过且不同，会显示共同基准、表格值和网页值，供选择保留哪一方。不会静默用旧表覆盖新计划。
- **空白和0**：空白表示待维护，0表示明确不安排。删除一个已维护单元格内容，表示将它恢复为待维护。
- **主表直接维护目录**：维护表和网页导出表的第一列按整个品牌区块纵向合并，同一品牌只显示一次，覆盖该品牌下的车型、版本、锁单、计划及品牌合计行；车型继续按明细区合并，版本逐行列出。新增时直接插入一行，填品牌、带年款的车型和月度计划量；不拆版本时将版本留空，系统识别为车型总量；需要拆分时再填写版本；也可复制一条原版本计划行并修改新行名称。改名直接修改相应名称，历史继续对应原版本编码。减少版本时删除整条SOP明细行，系统按停用处理并隐藏该行，保留已有计划和快照；减少车型可删掉该车型的所有版本计划行。若只改同一合并区域内的部分行，先在 Excel 取消相应合并，再分别填写名称。没有单独的新增区。
- **结构变更同步**：主维护文件中有新增、改名或删行时，请保存并关闭Excel，整批修改自动同步后重建汇总和行标识；单纯修改计划量仍约8秒检查一次。复制行新增时保留原行名称，新行填写不同的完整名称。普通数字输入不接受公式、负数或小数；不要改月份列或隐藏标识。锁单参考数不能改；年度、车型、品牌合计不作为输入，插删造成的公式变化在同步后自动重算。旧格式维护表先读入已保存修改，再升级。

主表保留“网页维护、导入Excel、导出”三个入口。长期表格同步放在“数据与规则”：点击“创建维护Excel”按需生成统一维护文件，建成后可“打开维护Excel”或“同步Excel”；保存后仍自动同步。即使 `input_file/` 中没有 `SOP计划维护.xlsx`，网页“导出”也使用统一数据生成 Excel；维护表存在时，导出前先读取其中已保存的修改。下载到其他位置的导出文件修改后，需要点击“导入Excel”回填。不含版本的导出用于查看车型汇总，不能回填或自动分摊到版本；锁单数、年度合计和汇总行不作为计划输入。以前下载的固定行格式仍能回填原计划，但插删行和改名需重新导出新版；未启用回填前的更早文件不含标识，必须重新导出。新插入行导入成功后，再次更名或删掉这些新行前请重新导出最新表，使其带上正式版本编号。表格修改的生效时间是成功同步或导入的时间；关闭服务后修改表格，应在重新启动后完成同步再作为正式计划使用。

没有维护表时，启动、后台同步、网页维护和网页导出均不自动生成 `SOP计划维护.xlsx`。需要长期维护表时，在“数据与规则”点击“创建维护Excel”才会在 `input_file/` 生成；普通网页导出的表格直接修改后可通过“导入Excel”回填，无需先创建维护表。

## 车型与版本变化

原始车型由选配比例文件的车型“by月”工作表名识别，品牌与车型从来源代际名提取；版本名称及版本锁单数取“版本／数量”明细行，车型锁单数取“交车锁单／数量”总行。版本显示去掉“2026款”等年款前缀，源代际信息仍保留用于对应销量。

不同年款分别展示和统计，年款写在车型名中，版本名仍不带年款前缀。独立的 `BETA` 标记或年款后的 `Beta` 尾缀只与同车型、同年款归在一起，例如 `V800 BETA 2026款` 与 `V800 2026款` 同组，`Z7 2025款Beta` 与 `Z7 2026款` 分开。汇总仅匹配共享规则中明确列出的完整代际，保留年款和其他代际限定词，不按同名车型扩大到其他年份。当前X4规则仅包含S9 2026款、S9T 2026款，S9 2024款和2025款分别保留。未标年款的手工版本不猜测归属；手工车型名称明确填写年款时才可与规则匹配。原始版本编码、代际、计划及历史保留，单代际模式仍可逐版本维护；原始车型锁单行分别读取再累加，不覆盖同年款BETA行。

顶部“代际”可选择“仅单代际”或“仅汇总代际”，默认单代际。两种视图互斥：汇总模式按规则隐藏成员单代际，单代际模式隐藏对应汇总项；没有参与汇总的车型在两种模式下都保留。汇总锁单按成员来源计算，SOP计划先按各成员车型年款应用总量优先规则，再自动相加；同名版本汇成一行，缺失不补0。汇总行只读，修改计划、名称或版本应切换至单代际；没有参与汇总的普通版本仍可维护。网页、维护表和新导出使用同一模式，切换前先同步旧维护表中的已保存修改；原计划、来源与历史记录保留。

汇总关系每次读取项目相对路径 `../订单分析/scripts/config/shared_config.py` 中的 `MERGE_GROUPS`，不复制车型清单、不缓存导入的Python模块。规则修改后刷新页面即可生效，页面也会自动检查变化；维护表随后同步重建。规则文件只读取字典常量，不执行其中代码。文件缺失、语法错误、成员重复归属或循环/嵌套汇总会明确报错，不继续用旧配置出表。已识别的旧汇总来源保留历史身份，移出配置后不会又以普通车型混入合计。部分旧来源表未带“汇总”后缀时，只按当前配置名称推导兼容别名，明确配置为成员的名称优先。内网部署需保持两个项目为同级目录。

汇总代际的月度计划、名称、删除操作在Excel中受保护，导回时也会核验；普通单代际版本仍可正常回填。先前导出的单代际表在切换汇总模式后仍可导入，汇总值自动重算。旧网页使用过期规则导出时会提示刷新，避免混用新目录与旧数量。不同年款各自对应“交车锁单”原值及版本SOP计划，品牌和总计再汇总这些独立年款；当前年款识别要求 `2025款` 这种格式，单写 `M5 2025` 不会自动剥离年份。

目录取自动识别来源与手工维护的全集，并保留已知历史产品。日常增删改直接在主表“网页维护”中完成；“数据与规则 → 来源与停用管理”保留来源关联、恢复启用、开始/结束计划月份等设置。Excel主表插行也可新增：无历史数量时从本月开始；明确填写历史计划时从最早填写月开始。网页新增默认从本月开始，未来上市版本可在来源与停用管理中指定未来月份。每个版本保留稳定编码，改名不会新建一套计划。

销量刷新发现新版本会补入目录，源文件暂时缺少旧版本时不会删掉旧计划。手工建立的版本在来源中首次出现时，品牌、车型、去掉年款后的版本名称唯一匹配则自动关联，保留手工记录的稳定编码和计划。多个代际同名时保留独立记录并提示核对，不盲目合并。原始文件改名或其他无法唯一匹配情况，可在原版本行选择“关联来源”。来源已维护计划/发货或同月数据冲突时拒绝关联，避免覆盖。

目录变动后自动更新同一份Excel的行和月份列，先读取已保存的表格修改，再生成新结构。已有版本日常只填计划量，新产品第一次填名称即可，不需要调整模板。Excel被打开占用时，保存并关闭后会完成更新。停用版本及已有计划保留，当月和未来计划停止输入，历史已有计划可修正；停用不会将未来已有数量清零，也不会把适用月份外的已有数值从汇总中删掉。旧快照保留当时的名称与记录。

## 同月锁单与SOP

页面、输入维护表与导出表的品牌顺序统一为：智界、享界、尊界、尚界、问界；其他品牌排在其后。SOP计划页的“显示问界”按钮可切换问界展示，勾选表示显示，并记住本机浏览器的选择。隐藏时，明细、筛选项、网页维护范围与合计均不含问界，底部合计会注明“不含问界”；目录、计划和历史数据仍保留。导出窗口的“包含问界”默认跟随页面，可独立勾选；不含问界的版本表导回时只更新其导出范围，不停用或清空问界。“恢复维护表格式”会恢复全部品牌（包含问界），长期维护表始终保留完整目录。

主表支持隐藏品牌、车型或版本行，并可恢复隐藏项。行隐藏只控制页面展示，当前筛选范围的合计仍包含隐藏行；它不会停用版本或修改计划，也不改变Excel导出范围（导出时另选范围）。当前隐藏状态会在本浏览器保留，包括网页删除后隐藏的已停用行；恢复显示可查看历史，不会重新启用版本。“已存视图、视图名称、保存视图、删除视图、恢复隐藏行”始终显示在表格上方，无需展开工具区；存在隐藏行时也可通过“恢复单行”选择恢复。保存后，选中对应已存视图即刻应用，无需再次点击确认。视图保存隐藏行、筛选、月份周期和展开状态；其他代际模式的视图标明模式并禁止误选，后续隐藏或恢复行不会改写已保存的视图。视图保存在当前浏览器中，不修改统一业务数据，也不会自动同步到其他电脑或浏览器。编辑草稿未保存时，先保存或取消，再切换视图或刷新数据。

主页面默认展示 **M+6（滚动12个月）**：前5个月＋当月＋未来6个月。例如2026年10月显示2026年5月至2027年4月，随当前月份自动滚动。12月后展示对应年份的年度SOP计划量，按该年1—12月完整范围汇总，包含滚动视图未显示的月份；锁单行在年度计划列留空，不再统计滚动12个月总量。顶部可以切换全年视图、年份和品牌、车型；“显示锁单”按钮可隐藏或显示全部锁单行，并记住本机浏览器的选择。点击“导出”可独立选择是否包含锁单、是否包含版本明细以及导出月份；默认勾选维护表的完整计划周期，保留版本明细且不含锁单行，是否包含问界跟随页面开关；也可切换当前视图月份或自选任意月份。导出为与输入维护表共用同一模板的Excel（.xlsx），标题、双行表头、列宽、行高、合并、历史月灰底、合计公式、冻结窗格和主表行布局一致，不再设置底部新增区。锁单以额外行及名称中的“锁单”标识展示，不新增指标列、数据说明列或说明索引；月份横向排列、指标分行，默认包含全部目录；勾选“仅导出当前筛选”时遵循品牌/车型/搜索筛选。不含版本时只导出只读车型汇总。含版本时同时列出车型汇总与版本明细，不能重复相加；车型锁单与版本锁单各取原始表对应行，不将车型锁单分摊到版本。选中12月时，在其后附该年1—12月完整SOP计划量（含未选月份），锁单行的年度计划列留空；不把不同年份加成滚动12个月总量。品牌和总计只累加车型汇总，避免与版本明细重复相加。蓝色表头、数字加粗、合计红色突出；已过去月份整列灰底，灰底本身不改变可维护范围。仍以**月份为列、指标为行**。车型折叠时分别显示锁单数和SOP汇总；展开后，先依次显示各版本的锁单行，再依次显示各版本的SOP计划行。例如M5有三个版本，则先三行锁单、后三行计划量。计划行的月份数字可以直接点击维护。车型锁单与同月各版本SOP计划量分别对照；源表两种锁单行有差异时保留原值，不强制对齐。合计区分完整数据与部分月份合计，缺失不补0；数据口径放在提示和表格说明中，数字不再带上标。

锁单来源读取 `input_file/鸿蒙智行锁单选配比例分析.xlsx`。车型锁单取各车型月表的**“交车锁单／数量”行**，版本锁单取同页**“版本／数量”明细行**；“已交付”不作为锁单。按用户确认，当前测试文件中两类锁单数不一致仍各自按原值展示，不用版本合计覆盖车型锁单，也不按车型总数分摊版本。品牌和总计按车型锁单求和。这个口径保存在 `data/source_settings.json`，后续刷新继续沿用。

当前来源月表覆盖2026年3～8月，未注明精确截止日。较新月份缺失不补0，文件修改日期不充当业务数据截止。锁单、预测销量、SOP计划和实际发货量分别保留，锁单不能替代匹配率公式中的实际发货量。

## 目录

- `input_file/`：原始销量文件，以及按需创建的 `SOP计划维护.xlsx`；维护表可填车型总量或版本月度计划量，销量刷新不会把维护表当作销量来源。
- `output_file/`：本地导出与核验文件。
- `data/sop.sqlite3`：计划、发货实绩、修改日志、每日快照、表格同步基准。
- `data/sales.json`：可刷新的锁单参考、版本映射及来源检查。
- `data/service.err.log`：服务日志。
- `data/backups/`：升级前的数据库备份。
- `data/backups/sop_excel/YYYY-MM/`：按业务月份归档的SOP Excel快照；文件名包含业务日期、快照类型及编号。
- `web/`：看板页面；无需联网加载页面资源。

服务运行时约每分钟检查input_file原始文件；连续两次检查文件大小与修改时间稳定后自动读取，通常保存后1—2分钟生效。刷新前先同步Excel中已保存的计划和新增版本，防止目录更新遗漏手工输入。文件读入失败或仍在写入时保留上次数据并自动重试，也可在“数据与规则”点击“刷新销量文件”立即读取。网页会载入更新后的锁单和目录。日常计划表保存约8秒自动同步，也可在“数据与规则”点击“同步Excel”。

## 已确认的日历和考核规则

- 北京时间，月度维护；本月计划为全月总量。
- 本月加未来6个月；每年9月扩展到次年12月。7月补到次年1月，8月补到次年2月。
- 每天24点保存全部已开放月份的快照；周日24点采用同一份快照考核。
- 提前0周：周一至周日为一周。1号所在周中属于考核月的天数**超过4天**，上一周为0周；否则1号所在周为0周。取该周日24点。2027年1月对应1月3日24点，2027年2月对应1月31日24点。
- 其余13周从0周每次倒推7天。单周匹配率为 `min(Y, Mi) / max(Y, Mi) × 100%`，W13～9各2%、W8～5各7.5%、W4～1各10%、W0为20%。
- 先按考核范围汇总计划、实绩，再计算匹配率；不平均版本百分比。缺失不补0、不重新分配权重，双零待口径确认。考核月结束、实绩结算且14周完整后，才显示正式成绩。

工作台命令窗口保持运行时，浏览器页面关闭仍可自动同步表格和保存快照。关闭命令窗口、关机或停止服务后不执行；重新启动后根据已留存修改日志还原遗漏截点，保留真实生成时间。不会把后来读入的Excel修改倒填到过去截点，也不会生成首次启用之前的历史计划。

## Excel快照备份

每日24点、周日24点和手工会议快照都会自动保存为 `.xlsx`。每个快照各一份文件，保留截点当时的版本和计划，后续调整不会覆盖历史备份。服务恢复后会补导尚未生成Excel的快照；生成失败时保留原快照并自动重试。

备份包括版本×月份的SOP计划表、含预测销量和维护信息的计划明细，以及快照编号、业务日期、截点和实际生成时间。空白与0保持区分。月份包含快照开放范围和该快照中已有计划的月份。

在“历史快照”页查看Excel生成状态；选中一份快照后，点击“下载Excel备份”即可获取。备份用于查阅和归档，修改备份文件不会同步到当前计划；日常使用“网页维护”，也可通过已有的 `input_file/SOP计划维护.xlsx` 同步。

## 运行与验证

Python 3.10以上，并安装 `requirements.txt` 中的 openpyxl。维护表、网页导出和快照备份在内网无 Node 或无 `@oai/artifact-tool` 时自动由 Python 生成；设置 `SOP_EXCEL_ENGINE=python` 可强制使用这一生成路径。本机若有 Node 和 artifact-tool，仍可使用原有生成器；`SOP_NODE_PATH` 指定 Node，`SOP_NODE_MODULES_PATH` 指定包含 artifact-tool 的 `node_modules`，本机链接可自动重建。服务只监听本机；以后部署内网需配置统一运行环境、身份认证和品牌权限。关闭工作台命令窗口即停止服务；运行信息同步写入data/service.err.log。建议停止后备份整个data及input_file目录。

执行 `python -m unittest discover -s tests -v` 验证日期、公式、不可变快照、零值和缺失、并发保存及表格同步。功能验收使用独立临时数据库，正式计划不预填测试数值。
